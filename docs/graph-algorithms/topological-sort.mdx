# 🔄 Topological Sorting (DAGs)

A **Topological Sort** of a Directed Acyclic Graph (DAG) is a linear ordering of vertices such that for every directed edge $u \rightarrow v$, vertex $u$ comes before $v$ in the ordering.

:::note Prerequisite
Topological sorting is **only possible** on Directed Acyclic Graphs (DAGs). If a graph contains a cycle, no valid linear ordering exists.
:::

## ⚙️ Algorithms for Topological Sort

### 1. Kahn's Algorithm (BFS In-Degree Method)
1. Calculate the **in-degree** (number of incoming edges) for every vertex.
2. Initialize a Queue with all vertices having `in-degree == 0`.
3. While Queue is not empty:
   - Dequeue vertex $u$ and append to topological order.
   - For each neighbor $v$ of $u$, decrement `in-degree[v]` by 1.
   - If `in-degree[v]` becomes 0, enqueue $v$.
4. If topological order contains fewer than $V$ vertices, the graph contains a **cycle**!

```python
from collections import deque

def kahns_topological_sort(v, adj):
    in_degree = [0] * v
    for u in range(v):
        for neighbor in adj[u]:
            in_degree[neighbor] += 1

    queue = deque([i for i in range(v) if in_degree[i] == 0])
    topo_order = []

    while queue:
        u = queue.popleft()
        topo_order.append(u)

        for neighbor in adj[u]:
            in_degree[neighbor] -= 1
            if in_degree[neighbor] == 0:
                queue.append(neighbor)

    if len(topo_order) != v:
        raise ValueError("Graph contains a cycle! No valid topological sort.")

    return topo_order
```

### 2. DFS-Based Topological Sort
Perform a DFS traversal and push vertices onto a stack after all outgoing edges/descendants are processed (post-order). Reverse the stack result.
