# 🎯 Competitive Programming Patterns & Practice Roadmap

This curated practice roadmap categorizes competitive programming graph problems by underlying algorithmic pattern. Master these core patterns to recognize graph problem signatures in technical interviews and contests.

---

## 📌 Problem Classification Matrix

| Pattern Category | Key Identification Clues | Benchmark Complexity | Target Algorithm |
| :--- | :--- | :--- | :--- |
| **Grid Traversal / Unweighted** | 2D matrix, 4-directional moves, minimum steps | $O(R \times C)$ | BFS |
| **Cycle Detection / Ordering** | Prerequisites, task scheduling, dependency DAG | $O(V + E)$ | Topological Sort (Kahn's / DFS) |
| **Single-Source Shortest Path** | Weighted edges $\ge 0$, minimum cost path | $O((V + E) \log V)$ | Dijkstra's Algorithm |
| **Negative Edge Weights** | Currency arbitrage, negative weight edges, cycle detection | $O(V \times E)$ | Bellman-Ford Algorithm |
| **Network Redundancy / MST** | Connecting all cities with minimum total cable length | $O(E \log E)$ | Kruskal / Prim |
| **Dynamic Connectivity** | Connecting components on the fly, redundant connections | $O(\alpha(N))$ | Disjoint Set Union (DSU) |
| **Single Point of Failure** | Critical connections, network disconnection | $O(V + E)$ | Tarjan's Cut Vertices / Bridges |
