# Suffix Array

## Introduction

The **Suffix Array** is a sorted array of all suffixes of a string. It is one of the most important data structures in string algorithms, enabling efficient solutions to problems like substring search, longest common substring, and palindrome detection.

For a string S of length n, the suffix array SA is an array of integers [0, n-1] that represents the starting positions of all suffixes, sorted in lexicographic order.

## Definition

For a string S = "banana":
```
Suffixes:
0: banana
1: anana
2: nana
3: ana
4: na
5: a
```

Sorted suffixes:
```
5: a
3: ana
1: anana
0: banana
4: na
2: nana
```

So the suffix array is: [5, 3, 1, 0, 4, 2]

## Construction: Prefix-Doubling Algorithm

The most common O(n log n) construction algorithm uses the concept of "doubling":
- Initially, sort suffixes by their first character (k=1).
- Then by their first 2k characters (using previously computed ranks).
- Repeat until k >= n.

### Key Idea

For suffix at position i, the pair (rank[i], rank[i+k]) is compared. Since ranks are already computed for k, this gives us a total order for 2k characters in O(n) time.

## Code Implementation

```javascript
// Build suffix array using prefix-doubling
function buildSuffixArray(s) {
  const n = s.length;

  // Initialize: sort by single character
  let SA = Array.from({ length: n }, (_, i) => i);
  let rank = s.split("").map(c => c.charCodeAt(0));

  // Temporary storage for new ranks
  let tmp = new Array(n).fill(0);

  // k = length of currently sorted prefixes
  for (let k = 1; k < n; k *= 2) {
    // Sort by (rank[i], rank[i+k])
    // Use a key-based sort
    const keyed = SA.map(pos => ({
      pos: pos,
      key: [rank[pos], pos + k < n ? rank[pos + k] : -1]
    }));

    keyed.sort((a, b) => {
      if (a.key[0] !== b.key[0]) return a.key[0] - b.key[0];
      return a.key[1] - b.key[1];
    });

    // Re-build SA from sorted order
    SA = keyed.map(x => x.pos);

    // Assign new ranks
    tmp[SA[0]] = 0;
    for (let i = 1; i < n; i++) {
      const prev = SA[i - 1];
      const curr = SA[i];
      tmp[curr] = tmp[prev] + (
        keyed[i].key[0] !== keyed[i - 1].key[0] ||
        keyed[i].key[1] !== keyed[i - 1].key[1]
        ? 1 : 0
      );
    }

    // Update rank array
    for (let i = 0; i < n; i++) {
      rank[i] = tmp[i];
    }

    // All ranks are unique when rank[n-1] === n-1
    if (rank[SA[n - 1]] === n - 1) break;
  }

  return SA;
}

// Build LCP (Longest Common Prefix) array
function buildLCP(s, SA) {
  const n = s.length;
  const rank = new Array(n);
  for (let i = 0; i < n; i++) {
    rank[SA[i]] = i;
  }

  const LCP = new Array(n).fill(0);
  let h = 0;

  for (let i = 0; i < n; i++) {
    const r = rank[i];
    if (r > 0) {
      // Find LCP between suffix SA[r] and SA[r-1]
      let j = SA[r - 1];
      while (i + h < n && j + h < n && s[i + h] === s[j + h]) {
        h++;
      }
      LCP[r] = h;
      if (h > 0) h--;
    }
  }

  return LCP;
}

// Usage
const s = "banana";
const SA = buildSuffixArray(s);
const LCP = buildLCP(s, SA);

console.log("Suffix Array:", SA); // [5, 3, 1, 0, 4, 2]
console.log("LCP Array:", LCP);   // [0, 1, 3, 0, 0, 2]

// Verify: print sorted suffixes
for (const idx of SA) {
  console.log(`${idx}: ${s.substring(idx)}`);
}
```

## Complexity Analysis

| Aspect | Prefix-Doubling | SA-IS (Linear) |
|--------|-----------------|---------------|
| Time | O(n log n) | O(n) |
| Space | O(n) | O(n) |
| Implementation | Simpler | Complex |

## LCP Array

The **LCP (Longest Common Prefix) Array** stores the length of the longest common prefix between consecutive suffixes in the suffix array. It is computed alongside the suffix array and is crucial for many suffix array applications.

For "banana":
```
SA:  [5,  3,  1,  0,  4,  2]
LCP: [0,  1,  3,  0,  0,  2]
```

## Applications

### 1. Substring Search
Find if pattern P exists in text T by binary searching in the suffix array. Time: O(|P| log n)

### 2. Longest Common Substring
The maximum value in the LCP array gives the longest common substring.

### 3. Burrows-Wheeler Transform (BWT)
The BWT, used in bzip2 and Bowtie, is constructed using the suffix array.

### 4. Bioinformatics
Suffix arrays are used in genome assembly, sequence alignment, and finding repeated patterns in DNA.

### 5. Number of Distinct Substrings
Sum of (n - SA[i]) - LCP[i] for all i gives the count.

## Advantages

1. **Space efficient**: O(n) vs suffix tree's O(n log sigma)
2. **Cache-friendly**: Sequential memory access patterns
3. **Versatile**: Supports many string operations

## Disadvantages

1. **Construction slower** than suffix trees for dynamic data
2. **LCP queries** require additional data structures (RMQ)
