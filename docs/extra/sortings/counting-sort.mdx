# Counting Sort

**Counting Sort** is a non-comparison sorting algorithm that works by counting the number of occurrences of each distinct value in the input. It achieves linear time complexity $O(n + k)$ where $k$ is the range of the input values, making it highly efficient for sorting integers within a bounded range.

## How It Works

1. **Find the range** of input values (minimum and maximum)
2. **Create a counting array** of size (max - min + 1), initialized to zero
3. **Count occurrences** of each value by incrementing the corresponding index
4. **Compute prefix sums** to determine the final position of each element
5. **Place elements** in the output array using the computed positions

### Step-by-Step Walkthrough

Given array: `[4, 2, 2, 8, 3, 3, 1]`

**Range**: min=1, max=8, so count array size = 8

**Count occurrences**:
```
Index:  0  1  2  3  4  5  6  7  8
Count: 0  1  2  2  1  0  0  0  1
(shifted: index 0 corresponds to value 1)
```

**Prefix sum**: `[0, 1, 3, 5, 6, 6, 6, 6, 7]`

**Place elements** (traverse input from right for stability):
- `1` -> position 0 -> output[0] = 1
- `3` -> position 5 -> output[5] = 3
- `3` -> position 4 -> output[4] = 3
- `8` -> position 6 -> output[6] = 8
- `2` -> position 3 -> output[3] = 2
- `2` -> position 2 -> output[2] = 2
- `4` -> position 5 -> output[5] = 4

Output: `[1, 2, 2, 3, 3, 4, 8]`

## Implementation

### Python

```python
def counting_sort(arr):
    if not arr:
        return arr
    min_val = min(arr)
    max_val = max(arr)
    range_val = max_val - min_val + 1

    count = [0] * range_val
    output = [0] * len(arr)

    # Count occurrences
    for num in arr:
        count[num - min_val] += 1

    # Compute prefix sum
    for i in range(1, range_val):
        count[i] += count[i - 1]

    # Place elements (traverse from right for stability)
    for num in reversed(arr):
        output[count[num - min_val] - 1] = num
        count[num - min_val] -= 1

    return output

# Example usage
arr = [4, 2, 2, 8, 3, 3, 1]
print(counting_sort(arr))  # Output: [1, 2, 2, 3, 3, 4, 8]
```

### JavaScript

```javascript
function countingSort(arr) {
    if (arr.length === 0) return arr;
    const minVal = Math.min(...arr);
    const maxVal = Math.max(...arr);
    const range = maxVal - minVal + 1;

    const count = new Array(range).fill(0);
    const output = new Array(arr.length);

    // Count occurrences
    for (const num of arr) {
        count[num - minVal]++;
    }

    // Compute prefix sum
    for (let i = 1; i < range; i++) {
        count[i] += count[i - 1];
    }

    // Place elements (traverse from right for stability)
    for (let i = arr.length - 1; i >= 0; i--) {
        output[count[arr[i] - minVal] - 1] = arr[i];
        count[arr[i] - minVal]--;
    }

    return output;
}
```

## Complexity Analysis

| Case        | Time Complexity | Space Complexity |
|-------------|----------------|-----------------|
| Best Case   | $O(n + k)$     | $O(k)$          |
| Average Case| $O(n + k)$     | $O(k)$          |
| Worst Case  | $O(n + k)$     | $O(k)$          |

Here $n$ is the number of elements and $k$ is the range (max - min + 1).

## When to Use Counting Sort

- **Integer values with a small range** (k is not significantly larger than n)
- **When stability is required** (with the prefix-sum approach shown above)
- **Radix Sort and Bucket Sort** use Counting Sort as a subroutine
- **Counting frequency** problems outside of sorting

## Limitations

| Limitation | Explanation |
|------------|------------|
| Bounded range | Fails when $k$ is very large (e.g., sorting 32-bit integers would need 4 billion buckets) |
| Non-negative integers | Requires adjustment for negative numbers; floating point needs normalization |
| Space overhead | When $k \gg n$, the space usage becomes prohibitive |

## Comparison with Comparison-Based Sorts

| Feature          | Counting Sort | Merge Sort | Quick Sort |
|------------------|---------------|------------|------------|
| Time (Worst)     | $O(n + k)$    | $O(n \log n)$ | $O(n^2)$    |
| Comparison-based | No            | Yes         | Yes         |
| Stable           | Yes           | Yes         | No          |
| Works on floats  | No (direct)   | Yes         | Yes         |

## Pseudocode

```
function countingSort(A):
    find min and max in A
    k = max - min + 1
    create count[0..k-1] initialized to 0
    create output[0..n-1]

    for each element x in A:
        count[x - min]++

    for i = 1 to k-1:
        count[i] += count[i - 1]

    for i = n-1 downto 0:
        output[count[A[i] - min] - 1] = A[i]
        count[A[i] - min]--

    return output
```
